## 📌 Overview

This repository contains a lightweight, dependency-free 2-player Tic-Tac-Toe game. It's built with vanilla JavaScript and organized into separate HTML, CSS, and JS files for clarity.

## ✨ Features

- ❌⭕ **Classic 2-Player Gameplay** — local play, alternating turns between X and O
- 🏆 **Score Tracking** — win counts for both players, saved across sessions via `localStorage`
- 🔄 **Reset Round** — clears the board while keeping current scores
- 🆕 **New Game** — resets the board and scores back to 0-0
- 🎨 **Animated Background & Responsive UI** — styled with a custom Google Font (Outfit)

## 🗂️ Project Structure

| File | Description |
| :--- | :--- |
| `index.html` | Game markup and structure |
| `styles.css` | All styling, including the animated background and score cards |
| `script.js` | Game logic — turn handling, win detection, score persistence |

## 🚀 How to Use

1. **Clone the repository:**

    git clone https://github.com/Tofayel5152/Tic-Tac-Toe-Game.git

2. **Navigate to the project directory:**

    cd Tic-Tac-Toe-Game

3. **Open `index.html`** directly in your browser to play — no build step or server required.
